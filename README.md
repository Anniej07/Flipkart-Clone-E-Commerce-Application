
# Flipkart Clone – E-Commerce Backend

## About the Project

Flipkart Clone is a backend e-commerce application inspired by Flipkart, developed using Java, Spring Boot, Spring Data JPA, Hibernate, and MySQL.

The project focuses on designing and implementing a real-world e-commerce database structure using JPA entity relationships and Hibernate ORM.

It is developed to understand backend architecture, database relationships, and REST API development.

## Technologies Used

- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Maven

## Database Design

The application follows an entity-based database design representing the core functionalities of an e-commerce platform.

### Main Entities

- User
- RoleEntity
- Address
- Seller
- Product
- Category
- Brand
- ProductImage
- Inventory
- Cart
- CartItem
- Wishlist
- Order
- OrderItem
- Review

## JPA Relationships Implemented

- One-to-One Mapping
- One-to-Many Mapping
- Many-to-One Mapping
- Many-to-Many Mapping
- Bidirectional Mapping
- Unidirectional Mapping
- JoinColumn
- mappedBy
- Enum Mapping

## Architecture

The backend follows a layered architecture:

- Entity Layer – Represents database tables.
- Repository Layer – Handles database operations.
- Service Layer – Contains business logic.
- Controller Layer – Exposes REST APIs.

## Project Objectives

- Design an e-commerce database structure.
- Understand JPA and Hibernate entity relationships.
- Implement primary keys and foreign keys.
- Understand bidirectional and unidirectional mappings.
- Develop backend functionality using Spring Boot.
- Perform database operations using MySQL.
